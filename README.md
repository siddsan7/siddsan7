## Selected experiments and projects

### Platonic Goal Transfer · machine learning research

I wanted to know which mistakes in training data would send a simulated robot to the wrong place. Before a follow-up experiment, I predicted that corrupting the name of its destination shape would hurt more than corrupting the floor description. Every method reached the correct destination on every trial, including a simple keyword baseline. That result changed what I could conclude from the test. I set the research question and recorded my prediction. AI agents designed, implemented, and ran the experiments. [Research case study](https://siddharthsanjay.com/projects/platonic-goal-transfer/) · [Code and results](https://github.com/siddsan7/platonic-goal-transfer)

### TruckerPath Dispatcher OS · AI product engineering

I built a logistics prototype that lets a dispatcher inspect the eight factors behind a freight recommendation. A separate Gemini assistant turns product feedback into a hypothesis and an experiment plan. The demo uses seeded data and simulates booking, so visitors can explore the full decision. [Product walkthrough](https://siddharthsanjay.com/projects/truckerpath-dispatcher-os/#walkthrough) · [Code](https://github.com/siddsan7/truckerpathpm)

### Harmonic Color Graph · recommendation systems and evaluation

I built a Python and FastAPI service that ranks possible next chords, then connected a LangGraph assistant that explains each choice using evidence from the ranking tools. I tested tool use and user intent separately. The assistant called the correct tools in all 40 benchmark cases and matched the user’s intent in 9 of the 12 cases scored for intent. [Engineering walkthrough](https://siddharthsanjay.com/projects/harmonic-color-graph/#walkthrough) · [Code](https://github.com/siddsan7/HarmonicColorGraph)
